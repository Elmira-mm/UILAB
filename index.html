01

Selection · exclusive

Radiobutton

Дозволяє вибрати рівно один варіант із набору взаємовиключних опцій. Якщо варіантів небагато й вибір лише один — це природний елемент для такої задачі.

Вибір способу доставки замовлення — доступний лише один варіант одночасно.

Use caseТариф, спосіб оплати, стать — короткий видимий список, один вибір.

02

Selection · multiple

Checkbox

Дозволяє вибрати один або кілька незалежних варіантів, або зафіксувати бінарний стан «так/ні» окремого пункту.

Налаштування сповіщень — будь-яка кількість пунктів може бути увімкнена одночасно.

Use caseМножинний вибір, згода з умовами, окрема функція увімкнена/вимкнена.

03

Input · free text

Text input

Поле для введення довільного тексту користувачем — імені, email, пошукового запиту тощо. Основний елемент для збору вільних даних.

Поле реєстрації профілю.

Use caseДані, які не можна обрати зі скінченного списку — текст, пароль, email.

04

Navigation · panels

Tabs

Групує пов'язаний контент у окремі панелі й показує лише одну з них за раз, без переходу на іншу сторінку.

Короткий опис товару чи функції — перша вкладка активна за замовчуванням.
Технічні характеристики: розмір, вага, матеріал — показуються без перезавантаження сторінки.
Відгуки користувачів з'являються у цій панелі після кліку на вкладку.

Use caseКілька розділів однакової ваги в межах одного об'єкта.

05

Action · trigger

Button

Запускає дію — відправку форми, збереження, перехід у інший стан інтерфейсу. Кнопка виконує операцію, а не переходить за адресою.

Use caseБудь-яка дія, що змінює стан застосунку — відправити, видалити, підтвердити.

06

Static · text

Text label

Статичний текст, який підписує поле або елемент керування, пояснюючи користувачу, що саме очікується. Сам по собі не інтерактивний.

Номер телефону
Підпис над полем вводу телефону в формі замовлення.

Use caseБудь-де, де поле вводу потребує пояснення свого призначення.

07

Navigation · route

Link

Переносить користувача на іншу сторінку, розділ або зовнішній ресурс. Виконує навігацію, а не дію над даними.

Повернутися нагору сторінки
Навігаційне посилання всередині документа.

Use caseПерехід між сторінками, до зовнішніх ресурсів або розділу цієї ж сторінки.

08

Assist · hint

Tooltip

Коротка підказка, яка з'являється при наведенні або фокусі на елементі та пояснює його призначення, не займаючи постійного місця на екрані.

CVV-код ? 3 цифри на звороті картки
Пояснення для поля, назва якого сама по собі неочевидна.

Use caseКоротке уточнення для іконки чи поля без постійного тексту.

09

Selection · list

Dropdown list

Дозволяє вибрати один варіант зі списку, прихованого, доки користувач не відкриє його — економить простір порівняно з радіокнопками при великій кількості варіантів.

Use caseОдин варіант із довгого списку — країна, місто, категорія.

10

Display · table

Data grid

Таблична структура для показу й порівняння багатьох записів одночасно, часто з можливістю сортування по стовпцях.

Проєкт ↕ Статус ↕ Дедлайн ↕ Пріоритет ↕
Клік на заголовок стовпця сортує рядки — типова поведінка data grid.

Use caseПерегляд і порівняння списку задач, замовлень, користувачів.
